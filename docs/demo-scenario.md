## 3. 말해도 되는 것 / 말하면 안 되는 것

**말해도 되는 것 (근거 있음)**
- 실제 데이터 사용: 단지 11개(공고·기사), 학교 47개(학교알리미 2026 학생 수), 정류소 351개·노선 95개(경기버스정보 배차)
- 입주 세대 6,228(2026) → 8,426(2027) → 9,323(2029), 종합 8.0 → 18.5 → 20.6점
- 버스 취약 단지의 **상대 순위**: 도보권 반경(400·600·800m)과 노선별 기존 이용객(0~50%, 0~80%)을 바꿔 6설정×300회 시뮬레이션 → **파라곤은 모든 설정에서 상위 3위권(75~100%)**, 중흥S-클래스는 반경 600m 이하에서만 항상 상위권, 힐데스하임은 기본 반경에서만 높음. 결론은 "파라곤 일대 우선 점검" 수준으로
- What-if로 시설 변경 효과를 즉시 비교할 수 있다는 것

**말하면 안 되는 것 (근거 약함)**
- "버스 부족도 41점"을 사실처럼 단정: 세대당 이용객(0.3)과 회당 승객(45)은 **가정**이고 점수가 0~70까지 움직임 → "가정 기준의 상대 비교"라고 말할 것
- "공원이 부족하다": 공원은 공식 대장 기준 접근성(규모별 유치거리 250m·500m·1km)으로 보며 대부분 단지가 기준 안 → **공원은 병목이 아님**. 오산역 금강펜테리움(공원 50점)과 중흥S-클래스(13점)만 상대적으로 취약. 공원의 규모·질·혼잡은 반영하지 않았음을 밝힐 것
- "학교 신설로 도시 전체가 크게 개선": 시험 결과(벌음동 일대 임의 위치, 2030) **마루초 이용률 115% → 77%로 크게 내려가지만**, 종합 부족도는 20.6 → 19.6로 **작음** → "학교 한 곳의 부담 완화를 정량 비교하는 도구"로 소개, 위치는 가정이라고 밝힐 것
- (해소됨) 성산초 136%: 통학구역 미확정 단지(더샵 오산역아크시티) 때문이었음 → 학구도(2026-09-20) 반영 후 해당 단지는 "통학구역 미확정"으로 학교 점수에서 제외, 성산초 값 사라짐
- 세교2-1 학교 위치: 확정 정보 없음 → "위치는 가정"이라고 반드시 밝힐 것
- 입주계획 편집 What-if: 세대수·입주 연도 변경, 신규 단지 추가가 가능. **2026년 이전 입주분은 학교 현원(학교알리미 2026)에 이미 포함된 것으로 보므로, 그 단지의 세대수를 바꿔도 학교 점수는 변하지 않음**(버스·공원은 변함). 신규 단지는 통학구역 자료가 없어 "가장 가까운 학교"로 배정. 시연 예: 슬라이더 2027 → 우미린 포레아시티 1,050 → 2,000세대 → 종합 +4.6점
- "최적 입지 = 지을 곳": 후보는 200m 격자점이며 토지이용·건축 가능 여부를 검토하지 않음 → "수요 중심 위치의 힌트"로만. 방식은 머신러닝이 아니라 전수 격자 탐색+시뮬레이션 최적화(docs/optimizer.md)
- 정류장 추천 효과(−5점대): 새 노선 신설(첨두 약 5.4분 배차) 가정에 좌우됨 → 크기 단정 금지

## 4. 예상 질문과 답변 초안

| 질문 | 답변 요지 |
|---|---|
| 데이터는 실제인가? | 학교(학교알리미 2026 + 학구도안내서비스 통학구역), 버스(경기버스정보 API), 단지(공고·기사). 공원은 오산시 도시공원 대장(공공데이터포털, 기준일 2025-12-22) 108개. 화면 배지로 출처 표시. |
| 점수 기준이 무엇인가? | 학교: 정원 초과+통학거리, 버스: 도보권 노선 첨두 이용률+거리, 공원: 규모별(1,500㎡·1만㎡·3만㎡) 최근접 공원까지 거리를 유치거리(250m·500m·1km)와 비교한 접근성. 1인당 면적은 기존 주민 인구를 몰라 분모가 왜곡되어 쓰지 않음. 계수는 코드의 PARAMS에 공개. |
| 가정이 틀리면? | 민감도를 직접 돌렸다. 절대값은 흔들리지만 파라곤은 상위 3위권 유지, 나머지 순위는 도보권 반경에 민감. 그래서 순위 중심으로 쓴다. |
| 단지가 11개뿐인가? | 좌표·입주시기를 확인한 단지만 반영. 일부는 미확인이라 제외했고 목록과 사유를 데이터 파일에 남겼다. |
| 기존 주민은? | 현재는 신규 입주분 중심. 기존 이용객 반영은 개선 과제. |
| 실제 정책에 쓸 수 있나? | 입주계획 확정 시 시설 점검 우선순위를 비교하는 용도. 정확한 수요 예측은 학구·실측 이용 데이터가 있어야 한다. |
| 다른 지역에도? | 데이터 로더(OSM, 공공데이터 API)가 지역 파라미터화되어 있어 확장 가능. |

- **서버/네트워크 실패:** 정적 파일이라 로컬 서버만 살아 있으면 됨. 지도 타일이 안 뜨면 백업 스크린샷으로 전환.
- **예상 밖 값:** 시연 직전에 2027, 2030 시나리오를 한 번씩 돌려 보고 값을 메모(위 표와 다르면 문서 갱신).
- **질문 폭주:** "가정·한계" 슬라이드를 마지막에 한 장 두고, 약점을 먼저 밝히는 편이 신뢰도에 유리.

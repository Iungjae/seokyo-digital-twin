# 최적 입지 추천 (격자 탐색 최적화)

## 동작
1. 단지 분포 범위에 0.006°(약 650m) 여유를 둔 영역에 **200m 격자**로 후보 지점을 생성한다(약 375곳).
2. 후보마다 선택한 시설(초등/중등학교, 정류장, 공원)을 **선택 연도에 개통**한다고 가정하고 전체 모델(`evaluate`)을 다시 계산한다.
3. 목적함수: **종합 부족도 감소량**(현재 시나리오 대비). 동률(포화)이면 **수요 가중 평균 접근거리 단축량**으로 가린다(100m 단축 = 0.05점 상당).
4. 상위 후보를 **400m 이상 간격**(비최대 억제)으로 5개 제시. 지도에 번호 마커와 후보 격자 히트(초록 농도)를 표시.
5. "시나리오에 추가"로 선택하면 이후 계산에 반영된다(다시 추천하면 감소 폭이 줄어든 다음 후보를 찾는 그리디 방식).

계산 시간은 약 1.8초(후보 375곳 × 모델 1.5ms). 진행 표시 양보는 `MessageChannel`을 쓴다(`setTimeout`은 비활성 탭에서 1초로 지연되어 15초가 걸렸음).

## 시설별 모델링 가정
| 시설 | 가정 |
|---|---|
| 초등/중학교 | 정원 900, 현원 0. 구역 학교보다 **가까운 단지**를 학구 재조정으로 배정받음 |
| 정류장 | **새 노선 1개 신설**로 모델링(첨두 배차 약 5.4분, 시간당 약 11회). 이 가정이 효과 크기(−5점대)를 좌우함 |
| 공원 | 면적 20,000㎡(근린생활권 근린공원 단계 충족) |

## 한계
- 후보는 격자점이라 **토지이용·건축 가능 여부(하천, 산지, 기존 건물)를 검토하지 않음**. 추천은 "수요 중심 위치"의 힌트이며 부지 확정이 아님.
- 시설은 한 번에 1개씩 그리디로 추가. 여러 시설의 **동시 최적 조합**은 아님.
- 학교는 정원 압박 점수(이용률 90%→0, 120%→최대) 개정 후 효과가 커짐(2029년 초등학교 1위 종합 −4.0점, 개정 전 −0.5점). 동점이면 접근거리 보조 기준으로 가림.
- 정류장 추천은 노선 신설이라는 가정에 민감. 실제로는 기존 노선 증차·경로 변경 등 대안이 있음.
- 모든 지표가 가정 기반이므로 추천은 **상대 비교**로만 해석.

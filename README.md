# 입주 전에 인프라 부족을 알려주는 ‘세교 디지털트윈’

오산시 세교2지구의 **입주계획**으로 학교·버스·공원 부족을 미리 예측하고, 시설·입주계획·가정값을 바꿔 보며 효과를 비교하는 웹 시뮬레이터입니다. (오산시 지역현안 기반 AI·SW 경진대회 출품작)

**체험 링크:** https://lim-yewon.github.io/seokyo-digital-twin/

## 실행
빌드가 필요 없는 정적 사이트입니다. 인터넷이 연결된 상태(지도 타일)에서 아무 정적 서버로 엽니다.

```bash
python3 -m http.server 8765
# http://localhost:8765
```

## 주요 기능
- 입주 시점 슬라이더(2026~2030), 종합·학교·버스·공원 레이어
- What-if: 시설(학교·정류장·공원)·세교2-1 통합학교·신규 단지 추가
- **입주계획 편집**: 단지 세대수·입주 연도 변경, 신규 단지 추가
- **최적 입지 추천**: 후보 격자 전수 탐색으로 부족도가 가장 줄어드는 위치 Top 5
- **가정값 패널 · 시나리오 저장·비교**: 모든 가정 계수를 화면에서 조정하고 나란히 비교

## 중요한 한계 (먼저 읽어 주세요)
- 모든 점수(0 충분 ~ 100 심각 부족)는 **가정 기반의 상대 비교용**입니다. 절대 수치로 해석하지 마세요. 가정 목록과 근거 구분은 [docs/assumptions.md](docs/assumptions.md).
- 예측은 **규칙 기반 수요–공급 시뮬레이션**이며 머신러닝이 아닙니다. 최적 입지 추천은 격자 전수 탐색 + 시뮬레이션 최적화이고, 후보는 토지이용·건축 가능 여부를 검토하지 않은 **격자점**입니다([docs/optimizer.md](docs/optimizer.md)).
- 기존 주민 인구, 학교 중등 추첨 배정, 신규 단지 통학구역은 반영하지 못했습니다. 민감도 분석은 [docs/sensitivity.md](docs/sensitivity.md).
- 종합 가중치(학교 .40 / 버스 .35 / 공원 .25)는 근거 없는 임의 값입니다.

## 데이터 출처
| 데이터 | 출처 |
|---|---|
| 학교 학생 수·학급 수 | 학교알리미(한국교육학술정보원) 2026학년도 공시 |
| 초등 통학구역·학교군 | 학구도안내서비스(한국교육시설안전원) 2026-09-20 |
| 학교 정보 | 교육정보 개방포털(NEIS) |
| 버스 정류소·노선·배차간격 | 경기도 버스정보 OpenAPI(공공데이터포털) |
| 공원 면적·좌표 | 전국도시공원정보표준데이터(오산시, 2025-12-22) |
| 단지 세대수·입주 시기 | 분양 공고·언론 보도(일부 미검증, `data/complexes.csv`의 status 열) |
| 지도·시설 좌표 | © OpenStreetMap contributors (ODbL), 단지 좌표는 카카오 로컬 API로 변환 |

배포본에는 가공된 결과(`data/facilities.json`, `data/complexes.csv`, `data/zones.json`)만 포함되어 있고, 원자료는 용량 때문에 제외했습니다. 재생성은 `scripts/`(fetch_*, build_*)를 참고하세요. 키가 필요한 스크립트는 환경변수로만 키를 받습니다.

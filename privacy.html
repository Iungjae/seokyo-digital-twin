개인정보처리방침

시행일: 입력 필요

1. 수집하는 개인정보

서비스는 회원가입·로그인·입력 양식이 없고, 운영자 서버로 개인정보를 전송하거나 저장하지 않습니다. 분석 도구(방문 통계, 광고 추적)도 사용하지 않습니다.

2. 이용자 브라우저에만 저장되는 정보

“시나리오 저장” 기능을 쓰면 시나리오 이름, 추가한 시설 위치, 입주계획 편집 내용, 바꾼 가정값이 이용자 브라우저의 로컬 저장소(localStorage, 키 seokyo.scenarios.v1)에 저장됩니다.

  • 이 정보는 이용자 기기에만 남고 운영자에게 전송되지 않습니다.
  • 비교표의 삭제 버튼이나 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있습니다.

3. 페이지를 열 때 외부로 나가는 요청

지도와 글꼴을 불러오기 위해 브라우저가 아래 서버에 직접 요청합니다. 이때 각 서버는 이용자의 IP 주소와 브라우저 정보를 받을 수 있으며, 처리 방식은 각 서비스의 방침을 따릅니다.

대상목적
tile.openstreetmap.org지도 타일
cdnjs.cloudflare.com지도 라이브러리(Leaflet)
cdn.jsdelivr.net글꼴(Pretendard)
웹 호스팅 서버페이지 제공. 접속 기록 보관 여부는 호스팅 업체 방침을 따름 호스팅 업체·방침 링크 확인 필요

4. 개인정보 보호책임자

이름입력 필요
연락처입력 필요

5. 방침 변경

처리 방식이 바뀌면(예: 방문 통계 도입) 이 페이지에 시행일과 함께 게시합니다.
